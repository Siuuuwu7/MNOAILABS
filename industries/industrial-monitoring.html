02 — Pipeline

How a frame becomes an action.

The same five-stage pipeline underpins every use case on this page — a predictable, debuggable path from pixels to decisions.

01 · INGEST
Camera stream

RTSP / ONVIF from any CCTV. No replacements, no rewiring. Frames sampled at the rate each task needs.

02 · PERCEIVE
Edge inference

Detection, pose, OCR and anomaly models run on a Jetson or local GPU. Nothing leaves your network by default.

03 · REASON
Event engine

Rules + ML turn raw detections into events — "PPE violation", "zone breach", "defect class 3" — with context and severity.

04 · ACT
Alerts & logs

SMS, WhatsApp, Slack, email, webhooks, sirens, light stacks or ERP/CMMS writes — whatever your ops team already uses.

05 · AUTOMATE
LLM layer

A private LLM sits on top: answers questions in Bangla/English, writes shift reports, drafts maintenance tickets, and powers the HSE chatbot.

Deep dive · Quality control

Every unit, inspected. Every defect, traced.

Defect classifiers run per camera, per product family. Each defect is logged with a clip, a class, a severity and the operator/station — so QA teams don't just see the problem, they see the context. Over time, the data powers closed-loop retraining: your model gets better the longer it runs.

  • Continuous learning with your own labelled data
  • Per-SKU thresholds and buyer-specific rules

04 — Deployment

Deployed your way — edge, on-prem, hybrid.

Edge

Jetson on the wall

Small, silent, GPU-accelerated devices co-located with cameras. Great for new sites or specific zones. Works offline; syncs when the WAN is up.

On-prem

Server in your rack

A central GPU server handles multiple cameras. Best for existing IT-managed factories. Everything stays inside your network.

Hybrid

Edge + private cloud

Edge handles real-time work; your private cloud does analytics, LLMs and long-term storage. Best of both — and easy to scale.
